# Simple Calculator

A terminal-based calculator written in C.

## Compile
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

## Run
./calculator

## Operations
Add, Subtract, Multiply, Divide, and Quit.

## Numeric behavior
Integer menu options. Arithmetic operations will be added in later tasks.

## Limitations
Task 0 implements the menu and quit option only.
Numeric input is expected.
